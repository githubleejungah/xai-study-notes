문항객관식 · OX는 바로 채점서술형은 모범 답 · Claude 채점개인이 추측한 예상 문제

답할 때 주의할 곳

  • 스트리밍: 강의에서는 웹소켓을 권하셨지만, 교재(11쪽)는 "단방향이라 SSE가 기본"이라고 씁니다. 시험이 교재 기준이니 SSE로 답하고, 웹소켓은 "양방향이 필요할 때"로 구분해 쓰세요.
  • FastAPI 비동기: 강의의 "바로 200 OK 주고 뒤에서 처리"는 async가 아니라 백그라운드 작업 · 큐 방식입니다. async는 I/O를 기다리는 동안 다른 요청을 처리하는 동시성이에요.
  • 숫자: 교재에는 MAX_ITERS 값이 없습니다. "반복 10회" 같은 보기는 종료 조건이 아니에요.
  • LLMOps: 강의에서 "운영을 맡는 LLM"처럼 들린 부분이 있었는데, 보통 LLMOps 는 LLM 앱을 운영하는 관행(프롬프트 · 평가셋 버전 관리, 회귀 평가, 모니터링)을 말해요. 운영 자동화 쪽은 AIOps 에 가깝습니다.
  • 세션 저장소: 강의 기준은 세션 · 대화 컨텍스트는 Redis, Cosmos DB 는 데이터 · 응답 보관이에요. Cosmos DB 는 캐시라기보다 파티션 키로 나눠 저장하는 NoSQL DB 입니다.
