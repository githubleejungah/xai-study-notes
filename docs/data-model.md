# 데이터 설계

## 정본 표

| 데이터 | 정본(고치는 곳) | 주인 | 사본 |
|---|---|---|---|
| 공부노트 내용 · 그림 · 용어 풀이 | `src/notes.html` 안의 `T` · `V` · 그림 상수 | 저장소 주인 | `notes/index.html`, claude.ai 아티팩트 |
| 퀴즈 문항 · 정답 · 해설 · 출처 | `src/quiz.html` 안의 `Q` 배열 | 저장소 주인 | `quiz/index.html`, claude.ai 아티팩트 |
| 푼 기록 · 적은 답 · 채점 결과 | 보는 사람 브라우저의 `localStorage` | 보는 사람 | 없음(서버로 보내지 않음) |

생성물과 아티팩트는 정본에서 다시 만들 수 있다. 서로 다르면 `src/`가 이긴다.

## 문항 구조 (`Q` 배열 한 칸)

| 필드 | 뜻 |
|---|---|
| `u` | 단원 |
| `lv` | 중요도(`h` 높음, `m` 보통) |
| `t` | 유형(`mc` 객관식, `ox`, `short` 서술형) |
| `q` | 질문 |
| `c`, `a` | 보기와 정답 번호(객관식), 정답 참·거짓(OX) |
| `w` / `m` | 해설(객관식 · OX) / 모범 답(서술형) |
| `s` | 근거(교재 쪽수 · 실습 자료). 비어 있으면 화면에 근거 줄을 그리지 않는다 |
