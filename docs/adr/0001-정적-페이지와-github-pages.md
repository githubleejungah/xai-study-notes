# ADR 0001 — 정적 페이지를 GitHub Pages로 공개하고 검색은 막는다

- 날짜: 2026-11-16
- 상태: 채택

## 맥락
기관이 수강생 산출물을 Padlet에 많이 올려 달라고 했다. claude.ai 아티팩트 링크는 비공개이고, 과정용 팀 계정이 끝나면 사라질 수 있다. 내용에는 강사님 강의 · 교재에서 온 것이 들어 있다.

## 결정
- 정적 HTML을 공개 저장소의 GitHub Pages로 올린다. 주소가 바뀌지 않고 무료다.
- 모든 페이지에 `noindex`, `robots.txt`에 전체 차단을 넣어 검색 노출을 막는다.
- 출처와 "개인 학습용 · 예상 문제는 추측"을 첫 화면에 밝힌다.

## 대안
- 아티팩트 링크만 공유: 계정이 끝나면 깨지고, 공개로 바꿔야 열린다.
- 비공개 저장소: 무료 계정에서는 Pages를 쓸 수 없다.
- 파일만 Padlet에 첨부: 상호작용(채점 · 확대)이 사라진다.

## 결과
- 링크를 아는 사람은 누구나 볼 수 있다. 검색 차단은 강제가 아니라 요청이다.
- claude.ai 전용 기능(채점 · 묻기)은 Pages에서 동작하지 않는다.
